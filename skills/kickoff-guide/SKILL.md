# /kickoff-guide — 착수보고서 작성 기준 가이드 생성

PMI/PRINCE2 표준 기반 작성 가이드를 **Markdown 파일**로 생성한 뒤 **HTML로 시각화**한다.

## 사용법

```
/kickoff-guide
/kickoff-guide --path ./docs        # 저장 위치 지정
/kickoff-guide --md-only            # Markdown만 생성 (HTML 생략)
```

---

## 실행 절차

### Step 1. 저장 경로 결정

- `--path` 인자가 있으면 해당 경로 사용
- 없으면 현재 작업 디렉토리에 저장
- 생성 파일명: `착수보고서_작성기준.md`

---

### Step 2. Markdown 작성 기준 문서 생성

[references/writing-guide.md](references/writing-guide.md)를 기반으로 아래 구조의 Markdown 파일을 작성한다.

생성 파일: `{경로}/착수보고서_작성기준.md`

```markdown
# 착수보고서 작성 기준

이 문서는 착수보고서를 처음 작성하거나 검토하는 PM·개발 리더를 위한 실전 작성 기준입니다.
각 섹션별 필수 항목, 좋은 예·나쁜 예, 체크리스트를 포함합니다.

## 빠른 체크리스트

착수보고서 제출 전 최종 점검:

- [ ] 기대 효과에 수치가 있는가?
- [ ] Out-of-scope가 명시되어 있는가?
- [ ] 마일스톤에 날짜와 완료 기준이 있는가?
- [ ] PM 이름과 연락처가 있는가?
- [ ] 예산이 세분화되어 있는가?
- [ ] 리스크마다 대응 전략이 있는가?
- [ ] 전제조건과 리스크가 연결되어 있는가?
- [ ] 성공 기준이 수치로 정의되어 있는가?
```

### Step 3. HTML 시각화

`--md-only` 옵션이 없으면 `claude-visualize:visualize` 스킬을 호출하여 HTML 파일을 생성한다.

```
Skill: claude-visualize:visualize
입력: 방금 생성한 착수보고서_작성기준.md
출력: 착수보고서_작성기준.html (같은 경로)
```

**visualize 스킬 호출 시 힌트**:

> 이 문서는 착수보고서 작성 가이드다. `report` 타입으로 시각화하되 다음 레이아웃을 따른다:
>
> - **Hero**: "착수보고서 작성 기준" + 부제 + 총 배점(100점) + 섹션 수(9개) KPI
> - **섹션 카드 그리드**: 9개 섹션을 3-col 카드로 나열. 각 카드에 배점 chip, 필수 항목 수, 아이콘 포함
> - **섹션별 상세**: 각 섹션을 펼쳐서 필수 항목 + 좋은 예(초록) + 나쁜 예(빨강) 나란히 표시
> - **흔한 실수**: danger 컬러 카드 7개
> - **빠른 체크리스트**: 인터랙티브 체크박스 (체크 시 취소선 효과)
>
> 좋은 예는 `--accent-2(#70e1cb)` 계열, 나쁜 예는 `--danger(#ff8c9f)` 계열로 구분한다.
> 체크리스트는 JS로 체크박스 토글 기능을 추가한다.

## 주의사항

- Markdown 파일은 `writing-guide.md`의 내용을 그대로 복사하지 않고, 독자가 읽기 쉽도록 목차·빠른 체크리스트를 추가하여 완성된 문서로 재구성한다.
- HTML은 반드시 단일 파일(self-contained)로 생성한다.
- 외부 폰트 로딩 실패 시에도 읽을 수 있도록 fallback 폰트를 포함한다.
