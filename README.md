# kickoff-review

착수보고서(Project Charter) 체크리스트 기반 검토 Claude Code 플러그인.

PMI/PRINCE2 표준을 기준으로 완성도·모호성·일관성·리스크를 분석하고 종합 점수(A~D)와 개선 권고사항을 제시한다.

## 설치

```bash
/plugins:add https://github.com/SeokRae/kickoff-review.git
```

## 사용법

```
/kickoff-review @"착수보고서.md"
```

## 검토 내용

- **완성도 체크**: PM 표준 기반 9개 필수 섹션 유무 및 품질 판정
- **모호성 탐지**: "적절히", "필요 시", "협의 예정" 등 모호 표현 탐지 + 개선 제안
- **일관성 검증**: 범위↔일정↔인력↔예산 간 불일치 탐지
- **리스크 평가**: 대응책 없는 리스크 식별, 누락 리스크 제안
- **종합 점수**: A(85+) / B(70~84) / C(50~69) / D(~49) 등급 산출

## 검토 기준

| 섹션 | 배점 |
|------|------|
| 프로젝트 개요 | 15점 |
| 범위 정의 | 15점 |
| 일정·마일스톤 | 15점 |
| 조직·R&R | 10점 |
| 예산·자원 | 10점 |
| 리스크·대응 | 15점 |
| 전제/제약 | 10점 |
| 성공 기준 | 10점 |
| 커뮤니케이션 계획 | +5 보너스 |
